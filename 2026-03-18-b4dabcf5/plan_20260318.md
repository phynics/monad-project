# Update Facade and Chat Engine Implementation Plan

## Overview
This plan exposes `GenerationParameters` (temperature, max tokens, etc.) through the `MonadCore` facade and ensures they are propagated through the `ChatEngine` and `ChatTurnContext` down to the `LLMService`.

## Scope Definition
### In Scope
- Update `ChatTurnContext` to store `GenerationParameters`.
- Update `ChatEngine` and its context building extension to accept and propagate `GenerationParameters`.
- Update `LLMStreamingStage` to pass `GenerationParameters` to `LLMService`.
- Update `MonadCore` facade initializers and `run` method to expose `GenerationParameters`.

### Out of Scope
- Modifying `LLMService` or its providers (they already support these parameters).
- Adding new generation parameters to the `GenerationParameters` struct.

## Current State Analysis
- **ChatTurnContext**: `Sources/MonadCore/Services/Chat/ChatTurnContext.swift`. Lacks `generationParameters`.
- **ChatEngine**: `Sources/MonadCore/Services/Chat/ChatEngine.swift`. `execute` method missing the parameter.
- **ChatEngine+ContextBuilding**: `Sources/MonadCore/Services/Chat/ChatEngine+ContextBuilding.swift`. `prepareSession` missing the parameter.
- **LLMStreamingStage**: `Sources/MonadCore/Services/Chat/Stages/LLMStreamingStage.swift`. Calls `llmService.chatStream` without passing parameters from context.
- **MonadCore**: `Sources/MonadCore/MonadCore.swift`. Initializers and `run` method missing the parameter.

## Implementation Phases

### Phase 1: Update ChatTurnContext
- **Goal**: Add `GenerationParameters` to the turn context.
- **Steps**:
  1. [ ] Update `ChatTurnContext` struct in `Sources/MonadCore/Services/Chat/ChatTurnContext.swift` to include `public let generationParameters: GenerationParameters?`.
  2. [ ] Update `init` and `forTurn` methods to handle the new property.
- **Verification**: Code compiles.

### Phase 2: Update ChatEngine and Context Building
- **Goal**: Propagate parameters through the engine.
- **Steps**:
  1. [ ] Update `ChatEngine.execute` in `Sources/MonadCore/Services/Chat/ChatEngine.swift` to accept `generationParameters: GenerationParameters? = nil`.
  2. [ ] Update `ChatEngine.prepareSession` in `Sources/MonadCore/Services/Chat/ChatEngine+ContextBuilding.swift` to accept `generationParameters: GenerationParameters?`.
  3. [ ] Pass `generationParameters` from `prepareSession` to the `ChatTurnContext` initializer.
- **Verification**: Code compiles.

### Phase 3: Update LLMStreamingStage
- **Goal**: Pass parameters to the LLM service.
- **Steps**:
  1. [ ] Update `LLMStreamingStage.process` in `Sources/MonadCore/Services/Chat/Stages/LLMStreamingStage.swift` to pass `context.generationParameters` to `llmService.chatStream`.
- **Verification**: Code compiles.

### Phase 4: Update MonadCore Facade
- **Goal**: Expose parameters to the public API.
- **Steps**:
  1. [ ] Add `private let defaultGenerationParameters: GenerationParameters?` to `MonadCore` in `Sources/MonadCore/MonadCore.swift`.
  2. [ ] Update all initializers to accept `generationParameters: GenerationParameters? = nil`.
  3. [ ] Update `MonadCore.run` to accept `generationParameters: GenerationParameters? = nil`.
  4. [ ] In `MonadCore.run`, pass the provided `generationParameters` (or `defaultGenerationParameters` if provided is nil) to `chatEngine.execute`.
- **Verification**: 
  - Code compiles.
  - Run existing tests: `swift test`.
  - Add a new test case in `Tests/MonadCoreTests` (if it exists) or a separate test file to verify parameter propagation.
