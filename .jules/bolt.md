## 2024-05-14 - Pre-calculate Query Vector Magnitude for Cosine Similarity Loops
**Learning:** In retrieval-augmented generation loops (e.g., `searchMemories`, `rankMemories`), the query vector is compared against thousands of memories using cosine similarity. Naively computing the magnitude of the query vector on every single comparison is a massive O(N) redundant operation, as the query vector never changes during a single search.
**Action:** Always extract the calculation of the query vector's magnitude (the denominator's first part in cosine similarity) outside of loops. Add an overloaded `cosineSimilarity` function that accepts this pre-calculated magnitude for the first argument to avoid re-calculating it on every iteration. This significantly speeds up vector searches in purely Swift/Accelerate implementations.
