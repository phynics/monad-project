## 2026-03-21 - [Vector Math Optimization in Loops]
**Learning:** During semantic searches and contextual rankings, `VectorMath.cosineSimilarity` was recalculating the Euclidean norm (magnitude) of the query vector on every iteration of the loop over all memories using Apple's Accelerate framework (`vDSP_svesqD`). Because the query vector remains constant across these iterations, calculating its magnitude multiple times results in O(N) redundant operations, significantly wasting CPU cycles.
**Action:** Created an optimized `VectorMath.cosineSimilarity(_:_:magnitudeA:)` overload that accepts the pre-calculated magnitude of the first vector. Pre-calculate this magnitude once prior to loops (e.g., in `MemoryRepository.searchMemories` and `ContextRanker.rankMemories`) to prevent redundant computations and improve throughput on large array scans.
